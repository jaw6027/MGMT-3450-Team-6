# Shared Class Project Guidelines

Multiple students develop this application in separate Codex chats connected to
the same shared GitHub repository. Follow these rules for every task:

1. Before making changes, retrieve the latest version of the repository. Fetch
   from GitHub and safely incorporate updates to the branch you are working on,
   preserving any existing local work.
2. Preserve all existing application functionality.
3. Do not overwrite or discard another student's work, including local changes
   and commits made through other Codex chats.
4. After completing a task, test the changes and commit them with a descriptive
   commit message. If tests cannot be run, explain the limitation.
5. Push completed changes to the shared GitHub repository.
6. Immediately before pushing, fetch again and check whether other students have
   pushed new changes. If they have, incorporate their changes safely and rerun
   relevant tests before pushing. If the push is rejected because the remote
   changed again, repeat this process.
7. If conflicting changes cannot be safely combined, stop and explain the
   conflict rather than overwriting anyone's work.
8. Never force-push to the shared repository.
