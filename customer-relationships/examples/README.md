# Laura’s Excel practice files

Open **Laura-CRM-Excel-Example.xlsx** in Excel. Start here explains the workbook; Customer example has three clearly fictional records, drop-down choices, sortable/filterable rows, and follow-up highlighting. Optional sample dates are grouped at the right. Replace example records with real records and save your workbook. No macros, external links, or automatic dashboard sync are included.

For a dashboard import, use **Laura-Marketing-Import-Example.csv**, or save only the workbook’s **Import example** sheet as CSV UTF-8. Its first row contains the exact marketing-import headers. Use **Import marketing leads** in Laura’s CRM, review the preview, then confirm. The fictional rows use stable example IDs so repeat imports are skipped. Give real leads their own unique IDs.

The Excel customer sheet and import sheet are independent examples. The import does not copy Excel contact names/emails, company types, sample versions/dates, or concerns: enter those inside the CRM. This workbook is a practice tracker, not a complete CRM backup. Use Complete backup in the dashboard to preserve conversation history and all CRM details.
